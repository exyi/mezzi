# Collect and standardize translations

Cancer.gov (authors of CTCAE) has a questionnaire generator for English, Czech and Slovak (and many other languages). The questions roughly correspond to possible Adverse Affects from CTCAE. Some questions are binary (yes/no). These translations are certified by CTCAE.

The form: https://healthcaredelivery.cancer.gov/pro-ctcae/build.php

> [!IMPORTANT]
> Run all scripts from inside this folder.
